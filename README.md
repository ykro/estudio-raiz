# Estudio Raíz

El código del sitio de Estudio Raíz tal como queda al final de la práctica de la Unidad 1 del curso **Idea to App: crea tu idea con IA sin saber programar**.

Sofía tiene un estudio de yoga y necesita un sitio donde se vean sus clases, sus horarios, sus planes y quién enseña. En el video lo construimos con AI Studio Build: un prompt inicial y cinco refinamientos, dos fotos hechas con Nano Banana y la publicación.

## Qué hay aquí

- Este repositorio se creó desde la pestaña GitHub de AI Studio durante la grabación. Cada commit es un envío que se ve en el video.
- `public/images/` tiene las dos fotos del video (`portada.jpg` y `equipo.jpg`).
- Los prompts del video están en la guía de la Unidad 1 del curso.

## Verlo en vivo

https://estudio-raiz.ai.studio es la versión de demostración del curso. Se construyó con los mismos prompts, así que puede verse un poco distinta de la del video: la IA no responde igual dos veces.

## Correrlo en tu computadora

Necesitas Node.js.

```
npm install
npm run dev
```

Abre http://localhost:3000.
